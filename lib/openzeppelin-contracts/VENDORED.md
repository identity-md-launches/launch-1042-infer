# Vendored OpenZeppelin Contracts

This is the ERC-20 dependency subset from OpenZeppelin Contracts **v5.0.2**:
https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.0.2

The five Solidity files and `LICENSE` were copied verbatim from that release using
`https://raw.githubusercontent.com/OpenZeppelin/openzeppelin-contracts/v5.0.2/`.
`SHA256SUMS` records their original contents. Verify from this directory with
`sha256sum -c SHA256SUMS`. The upstream MIT license is included in `LICENSE`.

All transitive imports needed by Infer are ordinary repository files. No package
installation, submodule, or network access is needed to compile them. Comments
inside upstream files can refer to an earlier last-modified version; the source
release for this subset is v5.0.2.
